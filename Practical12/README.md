# Practical 12: Event Management CRUD

## Technologies Used
- PHP
- MySQL
- XAMPP
- HTML and CSS

## Features
- Add events
- View events
- Update events
- Delete events
- Upload event posters
- Validate poster file type and size

## How to Run
1. Copy the Practical12 folder into C:\xampp\htdocs\
2. Start Apache and MySQL in XAMPP.
3. Create the event_management database in phpMyAdmin.
4. Open http://localhost/Practical12/ in your browser.
